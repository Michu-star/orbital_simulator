# Orbital Simulator

A working N-body simulator using the Runge-Kutta method.

## Installation

Go to the folder where you want to install the project.

Open PowerShell and run:

```powershell
git clone https://github.com/Michu-star/orbital_simulator.git
cd orbital_simulator

python -m venv .venv
.venv\Scripts\activate

pip install -r requirements.txt
python main.py
```

The simulator window should then open.
